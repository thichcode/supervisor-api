## Migration Guide

### 1. Update Dependencies

```bash
pip install -r requirements.txt
```

New required packages:
- `PyJWT>=2.8.0` - JWT authentication
- `opentelemetry-api>=1.20.0` - Distributed tracing
- `opentelemetry-sdk>=1.20.0` - Tracing SDK
- `prometheus-client>=0.19.0` - Metrics (already in requirements)

Optional packages:
- `opentelemetry-exporter-otlp>=1.20.0` - For OTLP export
- `k6>=0.50.0` - Load testing (install separately)

### 2. Update Configuration

Add to `.env`:

```env
# Authentication
JWT_SECRET=your-secure-secret-key-min-32-chars
WEBHOOK_INPUT_SECRET=your-webhook-secret

# OpenTelemetry (optional)
OTEL_EXPORTER_OTLP_ENDPOINT=http://tempo:4317
OTEL_SERVICE_NAME=supervisor-api

# Circuit Breaker (optional - defaults shown)
CIRCUIT_BREAKER_FAILURE_THRESHOLD=5
CIRCUIT_BREAKER_SUCCESS_THRESHOLD=2
CIRCUIT_BREAKER_TIMEOUT=30

# DLQ (optional - defaults shown)
DLQ_MAX_RETRIES=3
DLQ_RETRY_DELAY_SECONDS=60
```

### 3. Update Docker Compose

No changes required. New features are backward compatible.

## Feature Details

### Circuit Breaker

Automatically prevents cascading failures when downstream services are unavailable.

```
CLOSED → (5 failures) → OPEN → (30s timeout) → HALF_OPEN → (2 successes) → CLOSED
```

**Metrics:**
- `supervisor_circuit_breaker_state{service="..."}` - Current state (0=closed, 1=open, 2=half-open)
- `supervisor_circuit_breaker_failures_total{service="..."}` - Total failures
- `supervisor_circuit_breaker_successes_total{service="..."}` - Total successes

**Admin API:**
```
GET /admin/errors/circuit-breakers
```

### Dead Letter Queue

Failed requests are automatically retried up to 3 times with exponential backoff.

**Metrics:**
- `supervisor_dlq_pending_total` - Pending messages
- `supervisor_dlq_retrying_total` - Currently retrying
- `supervisor_dlq_resolved_total` - Successfully processed
- `supervisor_dlq_failed_total` - Permanently failed

**Admin API:**
```
GET  /admin/errors/dlq                    # List all DLQ entries
POST /admin/errors/dlq/{id}/retry         # Manual retry
DELETE /admin/errors/dlq/{id}             # Delete entry
```

### Authentication

Three authentication methods supported:

| Method | Header | Use Case |
|--------|--------|----------|
| JWT | `Authorization: Bearer <token>` | User/Admin auth |
| HMAC | `X-Signature: <sig>` | Webhook verification |
| API Key | `X-API-Key: <key>` | Service-to-service |

**Create Service Token:**
```python
from src.core.auth import create_service_token

token = create_service_token("n8n", ["read", "write"])
# Token valid for 30 days
```

**Create Admin Token:**
```python
from src.core.auth import create_admin_token

token = create_admin_token("thuong-admin")
# Token valid for 1 hour
```

### OpenTelemetry Tracing

Add distributed tracing to all operations:

```python
from src.core.tracing import traced, traced_llm_call, traced_db_query

@traced("process_request", "server")
async def process():
    ...

@traced_llm_call("gpt-4", "completion")
async def call_llm():
    ...

@traced_db_query("SELECT")
async def query():
    ...
```

**Export to Grafana Tempo:**
```yaml
# docker-compose.yml
services:
  tempo:
    image: grafana/tempo
    ports:
      - "4317:4317"  # OTLP gRPC
```

### Load Testing

**Quick Test:**
```bash
./load_test/quick_test.sh
```

**Full Load Test:**
```bash
k6 run \
  --env BASE_URL=https://api.example.com \
  --env WEBHOOK_SECRET=$WEBHOOK_SECRET \
  load_test/k6_load.js
```

**Expected Results (50 VUs):**
- p95 latency: < 500ms
- Error rate: < 5%
- Throughput: > 100 RPS

| Alert | Condition | Severity |
|-------|-----------|----------|
| HighErrorRate | error_rate > 5% | critical |
| CircuitBreakerOpen | any CB open > 1m | warning |
| DLQBacklogGrowing | dlq_pending > 100 | warning |
| LLMCostSpike | cost > $100/hour | warning |
| ServiceDown | availability < 99.9% | critical |
